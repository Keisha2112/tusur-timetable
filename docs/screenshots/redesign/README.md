## Результаты проверки

| Проверка | Результат |
| --- | --- |
| Сборка и подпись | Отладочная и релизная сборки прошли. Подпись релизного APK проверена. |
| Модульные тесты | 121 прошёл, 1 сетевой тест штатно пропущен. |
| Тесты на эмуляторе | 7 из 7 прошли на Android 16 и 7 из 7 на Android 6. |
| Android 16, обе темы | Прошли выбор факультета и группы, открытие текущего дня, переключение недель стрелками, свайпом и через список, возврат к сегодняшнему дню, открытие деталей и расписания преподавателя. |
| Смена группы и обновление расписания | В светлой теме проверены переход 714-2 → 716-1 → 714-2 и ручное обновление жестом. |
| Офлайн и сохранение выбора | В обеих темах после перезапуска открылись сохранённые занятия. При обновлении без сети появилось сообщение о работе с кэшем. Ручная тёмная тема сохранилась при перезапуске со светлой системной темой. |
| GitHub Releases | В обеих темах релизная сборка показала «Установлена последняя версия» после ручной проверки. |
| Android 6 | В подписанной сборке проверены запуск, загрузка расписания, список недель, детали занятия, настройки и переключение на тёмную тему. |
| Узкий экран | На Android 16 при ширине 360 dp и шрифте 150% проверены расписание, список недель, детали занятия и настройки. Длинное название занятия переносится целиком. |
